# Heart Disease Prediction Web App

## 📌 Project Overview

This project is a **Machine Learning-based web application** that predicts the likelihood of heart disease based on patient health parameters.
The application is built using **Python, Streamlit, and Scikit-learn**, and allows users to input medical data to get real-time predictions.

## 🎯 Objective

The goal of this project is to:

* Analyze health-related data
* Predict the presence of heart disease
* Provide a simple and interactive interface for users

---

## 🧠 Machine Learning Model

* Algorithm Used: Logistic Regression Classifier, Decision Tree Classifier, Random Forest Classifier
* Dataset: Heart Disease Dataset
* Model trained using classification techniques
* Performance evaluated using accuracy and classification metrics

## 🧾 Input Parameters

The model takes the following inputs:

* Age
* Sex
* Chest Pain Type
* Resting Blood Pressure
* Serum Cholesterol
* Fasting Blood Sugar
* Resting ECG
* Maximum Heart Rate Achieved
* Exercise Induced Angina
* Oldpeak (ST Depression)
* Slope of Peak Exercise
* Number of Major Vessels
* Thalassemia

---

## 📈 How It Works

1. User enters patient details in the web app
2. Input data is preprocessed and encoded
3. The trained ML model predicts the outcome
4. The app displays whether:

   * ✅ No Heart Disease
   * ❌ Heart Disease Detected
